# TransCourse 용어 사전

| **한국어** | **영어** | **설명** |
|---|---|---|
| 영상 | Video | 업로드된 원본과 후처리 산출물의 기준이 되는 단위 |
| 처리 작업 | ProcessingJob | 영상 하나에 대한 처리 유형 하나의 실행 단위. 영상마다 유형별로 하나씩 존재 |
| 처리 유형 | JobType | 썸네일 생성, 메타데이터 추출, 트랜스코딩 중 하나 |
| 시도 | Attempt | 처리 작업의 한 번의 실행. 시작할 때마다 시도 번호가 오른다 |
| 만료된 시도 | Stale attempt | 더 나중의 시도가 시작되어 결과를 기록할 수 없게 된 시도 |
| 재전달 | Redelivery | 리밸런싱이나 재시작으로 이미 받은 레코드를 다시 받는 것 |
| 선점 | Preemption | 재전달된 레코드가 RUNNING 작업의 새 시도를 시작하는 것 |
| 자동 재시도 | Retry | 실패한 작업을 정해진 횟수까지 다시 실행하는 것. 짧은 작업은 같은 레코드 재처리, 트랜스코딩은 재시도 토픽 경유 |
| 재시도 소진 | Exhausted | 자동 재시도를 모두 사용한 상태. 수동 재시도의 대상 |
| 수동 재시도 | Manual retry | 재시도 소진 작업을 API로 다시 실행하는 것 |
| 산출물 | Artifact | 썸네일 이미지와 HLS 플레이리스트·세그먼트 |
| 복구 폴러 | Recovery poller | 발행이 유실된 PENDING 작업을 재발행하는 스케줄러 |
| 유지 파티션 | Kept partition | 리밸런싱 전후 같은 컨슈머가 소유한 파티션 |
| 이동 파티션 | Moved partition | 리밸런싱으로 다른 컨슈머에게 넘어간 파티션 |
